# Organizer-provided benchmark input

The Track 3 solution expects an organizer-authorized copy of
`torch_transformer_benchmark.py` at this path:

```text
official/torch_transformer_benchmark.py
```

The attachment is intentionally absent from this public-safe package because
neither the file nor the adjacent Track 3 materials displayed a redistribution
licence. Obtain it from the official Track 3 Lark document using your own
authorized access. Do not commit it to this repository.

The public-update attachment used for the recorded result had:

```text
bytes   25017
sha256 5529c96a80799b51f68092e1444a30b17994554dffdf52da98ba701489a7f36e
```

The solution never modifies that file. It imports the organizer's model,
configuration, random-case generator, weight-copy routine, and correctness
predicate for reference-feasible checks.
